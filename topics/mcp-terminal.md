# PTY 输出、编码与回压

- 读历史记录需要有明确的响应上限。Rust 版的一轮实现按字节限制单次历史输出，使用 64 KiB 的上限。测试应覆盖超限输入和连续高速输出。
- UTF-8 字符可能跨读取边界，保留尚未收齐的字节。处理 ANSI 控制序列时，先确认编码和解析状态，避免把 UTF-8 的一部分当作控制字节。
- 同时测试中文输入、命令回显、中文输出和大块二进制。用字节级结果核对输入和输出，另外验证输出缓冲满时读取线程仍可前进。
- 记录足以定位会话和读取顺序的执行状态，退出后释放 PTY 及后台资源。
