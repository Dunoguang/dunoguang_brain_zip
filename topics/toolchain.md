# ARM 工具链

- 反汇编 ARM32 镜像时检查指令状态、目标三元组和入口对齐。Thumb 代码可用 `llvm-objdump` 按对应目标解码，再和符号及调用关系交叉验证。
- 用交叉编译器时记录 `--target`、架构选项和链接运行时。Windows、容器和 Android 宿主之间的工具版本应在复现记录中明确。
- 验证 ARM64 扩展时，用硬件能力信息和最小指令探针分别核对高级特性，再检查编译器的自动向量化输出。一轮 SM8650 实测中，不适合该设备的架构选项会生成设备无法执行的 SVE 指令。
- 打包前保留带符号 ELF、`System.map` 和实际内核配置。从最终镜像解包得到的代码和元数据应能追溯到同一次构建。
